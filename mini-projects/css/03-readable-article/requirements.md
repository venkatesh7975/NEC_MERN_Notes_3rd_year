# CSS-03: acceptance requirements

[Full brief](README.md) is authoritative for scope.

| Requirement | Evidence to submit |
| --- | --- |
| FR-1: Set line height, maximum text width and a spacing scale | A repeatable input/action and actual observed result |
| FR-2: preserve browser zoom | A repeatable input/action and actual observed result |
| Acceptance oracle | At 200% zoom text remains readable without clipping |

Record fixture values, expected result, actual result and pass/fail for each row. Identify any unmet requirement explicitly. Optional extensions cannot replace a required behavior.
