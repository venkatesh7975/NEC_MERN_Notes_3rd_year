# Build Selector laboratory

1. Read the [brief](README.md) and [acceptance requirements](requirements.md).
2. Prepare a minimal fixture for: A marked item uses the intended winning selector.
3. Implement the smallest working path: Style nested lists with element, class and attribute selectors.
4. Add the remaining FR behaviors, then the failure and boundary cases.
5. Repeat the tests after a clean restart or fresh load.
6. Submit source, run instructions and actual evidence. Explain one implementation tradeoff in 100–200 words.

Use the [submission guide](../../../00-course-overview/assessment.md). Faculty can use this brief as an elective or pair it with the module assignment. Do not publish classmates' details in fixtures.
