# HTML project bank

Official module 2 practice and extension bank. [Learning path](../../02-html/README.md). Projects 1–3 introduce concepts; 4–6 combine them; 7–8 investigate harder cases; 9–10 require a handoff and evidence. Later projects may use supplementary concepts and are outside the core classroom allocation.
