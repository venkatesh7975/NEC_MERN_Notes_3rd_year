120 contact hours. Session allocation below is a suggested teaching plan, not an official theory/lab split. Independent work, the full elective project bank and capstone need additional time.

## Stage 1: Foundations of Web Development

- Learn: Web evolution, Static vs Dynamic, Roles in Web.
- Practice: [Web foundations day 1](daily-practice/foundations/day-01/README.md) and [day 2](daily-practice/foundations/day-02/README.md).
- Classroom mini-project: [FOUNDATIONS-01](mini-projects/foundations/01-request-diary/README.md). For shared module 7/8, use one integrated artifact to demonstrate both tracks rather than doubling the hours.
- Assignment: [course-foundations](tasks/course-foundations/README.md) as independent work. In-class assessment samples the central behavior and a boundary case.
- Exit criteria: demonstrate the classroom project's expected output, explain its controlling concept and correct one failed test. Use a recommended 70/100 learning gate with a passing core behavior; faculty sets formal policy.

## After the core

Complete [supplementary tracks](11-supplementary/README.md) as needed, then the [capstone](capstone-project/README.md). Reserve approximately 24–40 independent hours for the capstone, adjusted by prior skill. Select one advanced/industry project for a portfolio; 150 projects are a choice bank, not a promise that all fit into 120 hours.

Start using basic Git for personal checkpoints from the HTML stage; module 9 covers the formal collaboration and release work. Introduce safe handling of user input throughout, then consolidate it in module 10.
