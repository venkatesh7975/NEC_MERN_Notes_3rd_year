# HTML

Official module 2; 10 hours shared across its tracks.

## Prerequisites

Web foundations.

## Learning objective

Explain and demonstrate semantics, text, links, lists, tables, forms through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../daily-practice/html/README.md).
3. [Assignment](../tasks/course-html/README.md).
4. [Ten mini-projects](../mini-projects/html/README.md) in increasing difficulty.
5. [Interview questions](../interview-preparation/html.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: A keyboard user can activate both contact links. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
