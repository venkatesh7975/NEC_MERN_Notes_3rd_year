# HTML interview preparation

## Explain the core idea

Question: Explain how HTML contributes to a web application.

Answer guide: HTML expresses meaning and structure. Use headings for hierarchy, lists for groups, tables for related rows and columns, and forms for inputs. A label's for attribute refers to a control's id; name identifies submitted data. Native form validation helps users but server validation remains necessary.

## Predict an output

Question: Trace the [worked example](../02-html/notes.md) without running it.

Expected result: Place in an HTML document; an empty or invalid email prevents normal form submission. Explain the input, operation and result, then introduce one boundary input and explain any required validation.

## Defend a project

Question: How did you satisfy create education, skills and project sections?

Answer criteria: cite the source implementation, demonstrate disabling styles still leaves a coherent resume, then show a failing input and explain its handling. Discuss one tradeoff and one limitation.
