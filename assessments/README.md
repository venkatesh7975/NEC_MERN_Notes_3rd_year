# Practical examinations and continuous assessment

Proposed examiner materials. Use fictional fixtures and announce permitted references before the examination.

## Foundation practical — 60 minutes

Build a semantic course registration page with name, email and course controls; present a timetable with table headers; apply a one-column mobile layout and a two-column wide layout. Demonstrate empty email rejection and keyboard access. Rubric: semantic structure 20, form correctness 20, responsive behavior 20, accessibility 20, explanation/evidence 20.

## JavaScript/React practical — 90 minutes

Given four lessons with stable IDs, render completion controls and a progress percentage. Add filtering by title without losing completion state. Reject duplicate IDs in fixture preparation. Demonstrate two of four completed = 50%, an empty search result and undo. Rubric: state correctness 35, events/rendering 20, edge cases 20, structure 15, viva 10. Use either vanilla JavaScript or React according to the stage being assessed, not both in one sitting.

## Backend/database practical — 90 minutes

Implement a course resource with title and positive hours, create/list/item reads, validation and missing-item responses. Demonstrate a SQL LEFT JOIN report or MongoDB targeted update according to the assigned variant. Provide seed/reset instructions. Rubric: API contract 30, database operation 25, validation 20, reproducibility 15, viva 10.

## Security and release viva — 30 minutes

Explain why CORS is not authorization, why HttpOnly does not prevent all XSS and how parameterized SQL separates data from syntax. Show a local safe text renderer and a reviewed Git diff. Discuss how to restore a previous build. Score each of five demonstrated explanations out of 20; do not award points for terminology without an example.

## Faculty moderation

Choose a variant students have prerequisites for. Test fixtures on the lab environment first. Preserve an unseen boundary case. Give partial credit based on observed behavior, record criterion scores and offer a correction exercise. These durations and weights are designed here, not printed in the syllabus.
