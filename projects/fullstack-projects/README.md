# Full Stack MERN Capstone Projects

## Capstone Project: Complete MERN Learning Management System (LMS)
- **Description**: Enterprise-grade learning platform supporting Students, Instructors, and Admins. Features include JWT authentication, course creation, markdown note reader, video streaming, interactive Monaco code runner, quizzes, assignments, certificate generator, and global leaderboard.
- **Tech Stack**:
  - **Frontend**: React 19, Vite, Tailwind CSS, Monaco Editor, React Markdown, Lucide Icons.
  - **Backend**: Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs, Multer.
- **Architecture**: Decoupled REST API + SPA Single Page Application containerized with Docker.
