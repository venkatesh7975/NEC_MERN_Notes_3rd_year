# JavaScript Hands-On Projects

## Project 1: Interactive LMS Quiz Engine Application
- **Description**: Single-page JavaScript application that renders multiple-choice questions, tracks countdown timer, calculates final score percentage, and persists high score rankings to browser `localStorage`.
- **Requirements**:
  - ES6+ Classes and Async/Await data loading.
  - Dynamic DOM creation and event listener handling.
  - LocalStorage persistence.

## Project 2: Weather Analytics Dashboard with Fetch API
- **Description**: Real-time weather search dashboard retrieving 5-day forecasts from OpenWeather API using `fetch()`, debounced search inputs, and dynamic SVG weather icons.
