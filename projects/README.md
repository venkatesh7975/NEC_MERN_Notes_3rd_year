# 🛠️ Projects Repository

This directory holds source code and specs for projects built throughout the curriculum.

---

## 📁 Projects Structure

```
projects/
├── html-css-projects/    # HTML5 & CSS3 Projects (Portfolios, Landing Pages)
├── javascript-projects/  # Vanilla JS Applications (Quiz App, Calculator, Weather App)
├── react-projects/       # React 19 Frontend Web Apps (Task Managers, Dashboard)
└── fullstack-projects/   # Fullstack MERN Projects (Auth System, REST APIs)
```

---

## 📌 Project Guidelines
- Keep each project in its own self-contained folder inside the relevant subfolder.
- Include a dedicated `README.md` inside each project folder describing setup instructions, features, and screenshots/demos.
