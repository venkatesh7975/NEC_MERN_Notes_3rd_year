# HTML & CSS Hands-On Projects

## Project 1: Personal Developer Portfolio & Resume
- **Description**: Build a multi-section responsive personal portfolio showcasing your skills, projects, work experience, and contact form.
- **Requirements**:
  - Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
  - Mobile-first responsive layout with CSS Flexbox & CSS Grid.
  - CSS custom variables for dark/light color palette.
  - Smooth scroll behavior and animated hover card states.
- **Folder Structure**:
  ```
  portfolio/
  ├── index.html
  ├── styles.css
  └── assets/
  ```

## Project 2: Modern SaaS Landing Page (Apple-Inspired)
- **Description**: A sleek product landing page featuring hero section with glassmorphism preview, pricing comparison cards, testimonials grid, and newsletter subscription form.
- **Requirements**:
  - Glassmorphic card design using `backdrop-filter: blur()`.
  - CSS keyframe gradient header background.
  - Form validation styling (`:invalid`, `:valid`).
