# JavaScript

Official module 4; 26 hours shared across its tracks.

## Prerequisites

HTML and CSS.

## Learning objective

Explain and demonstrate data types, operators, conditions, loops through tested examples.

## Exit criteria

Demonstrate project 1's expected result: 15 of 20 yields 75 percent and eligible; total 0 is rejected. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
