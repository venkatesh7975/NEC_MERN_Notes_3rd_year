# DevOps and deployment

Official module 9; 8 hours shared across its tracks.

## Prerequisites

A working local application.

## Learning objective

Explain and demonstrate git, github, ci/cd, docker, react deployment through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../daily-practice/devops/README.md).
3. [Assignment](../tasks/course-devops/README.md).
4. [Ten mini-projects](../mini-projects/devops/README.md) in increasing difficulty.
5. [Interview questions](../interview-preparation/devops.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: Log contains three distinct changes. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
