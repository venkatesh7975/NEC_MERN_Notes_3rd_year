# Curated external learning resources

Reviewed on 2026-10-08. These links are selected learning options, not an exhaustive ranking. Availability, pricing, and hiring processes can change. External content keeps its own license; this repository links to it and does not redistribute course PDFs.

| Topic | Resource | Level | Access | How to use it |
| --- | --- | --- | --- | --- |
| Web fundamentals | [MDN learning curriculum](https://developer.mozilla.org/en-US/docs/Learn_web_development) | Beginner | Free | Start with core modules; recreate each exercise without looking. |
| HTML CSS JS | [web.dev courses](https://web.dev/learn) | Beginner to advanced | Free | Use HTML, CSS, forms, accessibility, and performance tracks. |
| JavaScript | [JavaScript.info](https://javascript.info/) | Beginner to advanced | Free web; optional paid ebooks | Work through language, DOM, and asynchronous exercises. |
| Full stack | [Full Stack Open](https://fullstackopen.com/en/) | Intermediate | Free | Complete React and Node exercises after JavaScript fundamentals. |
| Full stack | [The Odin Project JavaScript path](https://www.theodinproject.com/paths/full-stack-javascript) | Beginner to intermediate | Free | Use project assignments for independent builds. |
| React | [React Learn](https://react.dev/learn) | Beginner to advanced | Free | Build the examples and explain state transitions aloud. |
| React | [You Might Not Need an Effect](https://react.dev/learn/you-might-not-need-an-effect) | Intermediate | Free | Review each effect in your project and justify its external synchronization. |
| Node | [Node Learn](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs) | Beginner to advanced | Free | Study runtime behavior alongside a small API. |
| Express | [Express installation and guides](https://expressjs.com/en/starter/installing.html) | Beginner to intermediate | Free | Check the installed major version before following older tutorials. |
| MongoDB | [MongoDB manual getting started](https://www.mongodb.com/docs/manual/tutorial/getting-started/) | Beginner | Free docs; hosted usage may cost | Practice CRUD on a local or test database. |
| MongoDB | [Atomicity and transactions](https://www.mongodb.com/docs/manual/core/write-operations-atomicity/) | Advanced | Free | Test concurrent writes rather than relying on a diagram. |
| Mongoose | [Mongoose schemas guide](https://mongoosejs.com/docs/guide.html) | Intermediate | Free | Compare validation, indexes, and update behavior. |
| TypeScript | [TypeScript handbook](https://www.typescriptlang.org/docs/) | Beginner to advanced | Free | Port one reducer and validate external data at runtime. |
| Testing | [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/) | Intermediate | Free | Test visible outcomes through accessible roles. |
| Testing | [Playwright documentation](https://playwright.dev/docs/intro) | Intermediate | Free | Test the built app and keyboard workflows. |
| Build tools | [Vite guide](https://vite.dev/guide/) | Beginner to intermediate | Free | Understand development proxy versus production hosting. |
| Security | [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Intermediate to advanced | Free | Use targeted authentication, session, CSRF, and input-validation references. |
| Accessibility | [WAI tutorials](https://www.w3.org/WAI/tutorials/) | Beginner to advanced | Free | Review forms, images, tables, and page structure. |
| Git | [Pro Git book](https://git-scm.com/book/en/v2) | Beginner to advanced | Free | Practice branches, conflict resolution, and recovery in a sandbox repository. |
| API contracts | [OpenAPI specification](https://spec.openapis.org/oas/latest.html) | Intermediate | Free | Write and validate a small API contract. |
| Practice | [freeCodeCamp](https://www.freecodecamp.org/learn/) | Beginner | Free | Supplement notes with independent exercises; verify current course tracks. |
| DSA practice | [LeetCode study plans](https://leetcode.com/studyplan/) | Intermediate | Mixed free and paid | Practice patterns and explain complexity; avoid memorizing company tags as predictions. |
| Interview practice | [GreatFrontEnd](https://www.greatfrontend.com/) | Intermediate to advanced | Mixed free and paid | Optional UI and frontend interview practice; repository exercises remain free. |
| Browser debugging | [Chrome DevTools](https://developer.chrome.com/docs/devtools/) | Intermediate | Free | Capture traces and network evidence while debugging. |
| Deployment | [Docker getting started](https://docs.docker.com/get-started/) | Intermediate | Free docs; service plans vary | Run the sample MongoDB stack and learn volume persistence. |
| Company | [Amazon how we hire](https://www.amazon.jobs/content/en/how-we-hire) | All | Free | Confirm the role format and prepare evidence-based behavioral stories. |
| Company | [Google hiring process](https://www.google.com/about/careers/applications/how-we-hire/) | All | Free | Review official process and ask the recruiter for your role format. |
| Company | [Microsoft technical interviewing](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing) | All | Free | Use official preparation guidance; practice clarification and reasoning. |
