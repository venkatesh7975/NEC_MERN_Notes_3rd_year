# Learning paths

Choose a goal, follow prerequisite edges, and use the exit evidence rather than the number of pages read. Study estimates describe first practice, not guaranteed mastery.

- [80/20 MERN Developer](80-20-mern-developer.md) — Build useful features quickly, then revisit weak concepts.
- [Complete MERN Developer](complete-mern-developer.md) — Explore the whole mapped landscape; this route is a goal, not a completeness certification.
- [Frontend Developer](frontend-developer.md) — Build accessible, responsive, recoverable browser experiences.
- [React Developer](react-developer.md) — Reason precisely about component identity, state ownership, and remote data.
- [Backend Developer](backend-developer.md) — Protect data and expose clear contracts.
- [Node.js Developer](nodejs-developer.md) — Understand the runtime and manage finite resources.
- [Full-Stack Engineer](full-stack-engineer.md) — Connect interface behavior to API and persistence guarantees.
- [Interview Preparation](interview-preparation.md) — Prioritize product-company and startup evaluation while adapting to the actual role.
- [Production Engineer](production-engineer.md) — Operate safely under release, dependency, and data failure.
- [Advanced MERN Engineer](advanced-mern-engineer.md) — Study specialization because a workload justifies it.
