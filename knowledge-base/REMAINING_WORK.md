## Working sequence

Start with the [80/20 path](paths/80-20-mern-developer.md), select a P0 gap from the [index](INDEX.md), and submit one deeply verified lesson or project feature. Review against [the topic template](templates/topic.md) and [contribution guide](../CONTRIBUTING.md). Keep counts derived from data and avoid increasing file counts at the expense of runnable evidence.

The comprehensive route is a destination, not an assertion that every referenced concept has full treatment. The [project registry](data/projects.json) links runnable core source for all 20 entries. Implemented-learning does not claim every advanced extension in a packet. Commerce has atomic single-product reservations and signed payment test contracts; real processing and reservation expiration remain extensions. Chat has durable writes and replay; presence and read states remain extensions. See [downloads](downloads/README.md) and [verification](VERIFICATION.md) for artifact and execution evidence.
