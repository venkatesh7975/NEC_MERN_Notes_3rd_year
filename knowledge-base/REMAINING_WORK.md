## Working sequence

Start with the [80/20 path](paths/80-20-mern-developer.md), select a P0 gap from the [index](INDEX.md), and submit one deeply verified lesson or project feature. Review against [the topic template](templates/topic.md) and [contribution guide](../CONTRIBUTING.md). Keep counts derived from data and avoid increasing file counts at the expense of runnable evidence.

The comprehensive route is a destination, not an assertion that every referenced concept has full treatment. The [project registry](data/projects.json) makes implementation status independently reviewable.
