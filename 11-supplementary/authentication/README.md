# Authentication and authorization

SUPPLEMENTARY / INDUSTRY SKILLS. No official hours assigned.

## Prerequisites

Security and REST APIs.

## Learning objective

Explain and demonstrate passwords, sessions, identity, ownership, roles through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../../daily-practice/authentication/README.md).
3. [Assignment](../../tasks/course-authentication/README.md).
4. [Ten mini-projects](../../mini-projects/authentication/README.md) in increasing difficulty.
5. [Interview questions](../../interview-preparation/authentication.md).
6. [Capstone application](../../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: Correct input matches; wrong input fails. Then explain one failing input and how you handled it. Use the [roadmap](../../ROADMAP.md) for the required classroom selection.
