# Supplementary / industry skills

These tracks support MERN project development but are not separately named in the supplied syllabus. No official hours are assigned.

- [Mongoose](mongoose/README.md): schemas and model contracts after MongoDB.
- [Authentication and authorization](authentication/README.md): identity and ownership after web security.
- [Full Stack MERN](fullstack/README.md): UI/API/database integration.

Advanced project-bank topics such as migrations, optimistic edits, upload limits and rollback practice are optional extensions. Complete core learning gates before attempting the [capstone](../capstone-project/README.md).
