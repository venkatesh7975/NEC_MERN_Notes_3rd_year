# Web foundations

Official module 1; 6 hours shared across its tracks.

## Prerequisites

No programming prerequisites.

## Learning objective

Explain and demonstrate url, request, response, frontend, backend through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../daily-practice/foundations/README.md).
3. [Assignment](../tasks/course-foundations/README.md).
4. [Ten mini-projects](../mini-projects/foundations/README.md) in increasing difficulty.
5. [Interview questions](../interview-preparation/foundations.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: Reload index.html; record document and stylesheet requests. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
