# SQL

Official module 8; 8 hours shared across its tracks.

## Prerequisites

Records and basic data types.

## Learning objective

Explain and demonstrate sql versus nosql, crud, keys, joins through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../../daily-practice/sql/README.md).
3. [Assignment](../../tasks/course-sql/README.md).
4. [Ten mini-projects](../../mini-projects/sql/README.md) in increasing difficulty.
5. [Interview questions](../../interview-preparation/sql.md).
6. [Capstone application](../../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: Three seeded rows appear in ID order. Then explain one failing input and how you handled it. Use the [roadmap](../../ROADMAP.md) for the required classroom selection.
