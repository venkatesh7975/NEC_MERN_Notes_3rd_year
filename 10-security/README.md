# Web security

Official module 10; 5 hours shared across its tracks.

## Prerequisites

Forms, HTTP and databases.

## Learning objective

Explain and demonstrate owasp basics, sql injection, xss, csrf through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../daily-practice/security/README.md).
3. [Assignment](../tasks/course-security/README.md).
4. [Ten mini-projects](../mini-projects/security/README.md) in increasing difficulty.
5. [Interview questions](../interview-preparation/security.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: <b>hello</b> appears literally. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
