| Area | Status and run context |
| --- | --- |
| HTML/CSS | Standalone browser examples; advanced media needs its referenced assets or explicit fallback |
| JavaScript basic/intermediate/advanced | Node scripts with console output; browser exercises require their HTML files |
| ClassProjects and javascript/p3 | Preserved duplicate classroom URLs; javascript/p3 is the canonical exercise location |
| React | Component/hook fragments, requiring a React host; simulated API behavior is not a live service |
| Node | Core-module demos; basic server auto-stops after two seconds |

| MongoDB directory | Mongoose model/helper fragments, requiring connection and models from caller |
| MySQL basic/intermediate | Run schema before queries; seed meaningful data before interpreting empty output |
| MySQL advanced | Requires its standalone setup.sql before transaction example |
| Counter/color project | Existing browser implementation; shared as reference, not evidence of every student's completion |
| New mini-project bank | Student build specifications, not 150 finished applications |
