# 📚 Web Development Learning Resources & Tools

## Official Documentation Links
- [MDN Web Docs](https://developer.mozilla.org/) — Authoritative reference for HTML, CSS, and JS APIs.
- [React 19 Official Documentation](https://react.dev/) — Interactive guides and component reference.
- [Node.js Documentation](https://nodejs.org/docs) — Official Node.js API guides.
- [Express.js Guide](https://expressjs.com/) — Web framework docs and middleware routing guides.
- [MongoDB University](https://learn.mongodb.com/) — Free courses on NoSQL modeling & aggregations.

## Recommended Tools & Libraries
- **Code Editors**: VS Code, Monaco Editor.
- **UI Components & Icons**: Tailwind CSS, Framer Motion, Lucide Icons.
- **API Testers**: Postman, Hoppscotch, Bruno.
- **Hosting & Cloud**: Vercel (Frontend), Render (Backend), MongoDB Atlas (Cloud Database).
