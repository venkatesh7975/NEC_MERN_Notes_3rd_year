# Teaching references

Use primary documentation for version-sensitive behavior. Record the version used by each runnable submission.

- [MDN HTML](https://developer.mozilla.org/en-US/docs/Web/HTML): semantic elements and form behavior.
- [MDN CSS](https://developer.mozilla.org/en-US/docs/Web/CSS): cascade and layout.
- [MDN JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript): types, operators and control flow.
- [React interactivity](https://react.dev/learn/adding-interactivity): props, events and state.
- [Node documentation](https://nodejs.org/docs/latest/api/): runtime modules and asynchronous APIs.
- [Express error handling](https://expressjs.com/en/guide/error-handling/): middleware and version differences.
- [MongoDB manual](https://www.mongodb.com/docs/manual/): document operations.
- [Mongoose validation](https://mongoosejs.com/docs/validation.html): unique indexes and update validation.
- [MySQL manual](https://dev.mysql.com/doc/refman/8.4/en/): SQL and transactions.
- [Git book](https://git-scm.com/book/en/v2): snapshots and collaboration.
- [Docker documentation](https://docs.docker.com/): containers and persistent storage.
- [GitHub Actions documentation](https://docs.github.com/en/actions): CI workflows.
- [OWASP XSS prevention](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html): safe sinks and output encoding.
- [OWASP CSRF prevention](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html): CSRF controls.
- [OWASP SQL injection prevention](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html): parameterized queries.

The supplied syllabus is transcribed in [syllabus-transcription.md](syllabus-transcription.md). Web references explain implementation; they do not expand official course scope.

- [Vite setup](https://vite.dev/guide/): React host scaffolding and runtime prerequisites.
- [Docker startup order](https://docs.docker.com/compose/how-tos/startup-order/): dependency order versus readiness.
