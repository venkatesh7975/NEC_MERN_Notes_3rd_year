# CSS

Official module 3; 14 hours shared across its tracks.

## Prerequisites

HTML.

## Learning objective

Explain and demonstrate selectors, box model, flexbox, grid, responsive layout through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../daily-practice/css/README.md).
3. [Assignment](../tasks/course-css/README.md).
4. [Ten mini-projects](../mini-projects/css/README.md) in increasing difficulty.
5. [Interview questions](../interview-preparation/css.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: A 240px border-box card stays 240px wide including padding. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
