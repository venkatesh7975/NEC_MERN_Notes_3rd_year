# MERN Stack Knowledge Base

Learn the web, build full-stack JavaScript applications, prepare for product-company and startup interviews, and understand the engineering decisions behind reliable systems. This living open-source knowledge base is for beginners, developers, interview candidates, and trainers. The institutional curriculum is one optional view, and useful original URLs remain available.

## 50 open-source full-stack project source links

These are **50 distinct external applications**, in addition to the source projects maintained in this repository. Each upstream repository, README, license metadata and client/server layout was inspected on **2026-10-09**. They have not all been installed, executed or security-audited here. Stack labels describe the reviewed version; GraphQL, Firebase, SQL, Python and Ruby alternatives are identified explicitly.

Start with a small CRUD app, then study one domain such as commerce, chat, learning or expenses. For interview preparation, trace one request through UI, validation, authorization, persistence and response; reproduce the feature, add a boundary test, and explain a tradeoff. Use each upstream README for setup and environment variables.

Older examples can depend on unsupported Node releases, Create React App or discontinued hosting. Use them to study behavior and practice migration; review dependencies before running them. The license links point to upstream terms. Several larger products have an open-source core plus separately licensed enterprise or optional packages, as recorded in the [project metadata register](knowledge-base/resources/external-projects.json).

## Study in the browser

```bash
git clone https://github.com/venkatesh7975/NEC_MERN_Notes_3rd_year.git
cd NEC_MERN_Notes_3rd_year
python -m http.server 8000
```

Open `http://localhost:8000/knowledge-base/explorer.html` to search concepts, filter priority/difficulty/depth, read guides, track reviewed concepts, and export progress. Open `/projects/knowledge-base/learning-lab/` for six apps, `/interview-handbook/study.html` for answer practice, or `/` for the preserved portal. Serving over HTTP allows modules and JSON data to load consistently. Progress stays in your browser; export it for backup.

For MERN apps, follow the [workspace setup](projects/interview-ready/mern-workspace/README.md). It requires Node 22.12 or newer and MongoDB. The explorer and UI lab need no npm installation.
