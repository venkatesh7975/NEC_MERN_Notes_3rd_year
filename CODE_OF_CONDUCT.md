# Community code of conduct

Everyone is welcome regardless of country, background, experience, or identity. Be respectful, give specific technical feedback, credit original work, and allow for different first languages. Ask for evidence without attacking the person. Harassment, discrimination, threats, targeted sexual content, and publishing private information are unacceptable.

Maintainers may remove inappropriate contributions, explain corrective action, or restrict participation to protect the community. Apply expectations consistently and allow respectful clarification or appeal.

For concerns, use a private contact method published on [the maintainer's GitHub profile](https://github.com/venkatesh7975). If none is available, request a private contact channel without publishing sensitive details. This policy covers repository discussions, issues, pull requests, and explicitly associated community spaces.
