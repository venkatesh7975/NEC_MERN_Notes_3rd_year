# Prerequisites and entry check

You should be able to create folders, edit a text file, locate a file by path and open a browser. Prior framework experience is unnecessary.

## Entry activities

1. Create a folder and an index.html containing a heading; open it in a browser.
2. Open developer tools, find the heading in Elements and read one console message.
3. Open a terminal in the folder and list its files.
4. Explain the difference between saving a source file and refreshing a browser.

If these are unfamiliar, complete them with faculty before module 1. Before React, demonstrate a JavaScript function, an array transformation and an event listener. Before Node, explain promises and errors. Before databases, distinguish a record, identifier and relationship. These are teaching prerequisites, not additional official modules.
