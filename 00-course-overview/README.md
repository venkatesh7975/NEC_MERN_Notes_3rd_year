# Course overview

Start with [the curriculum](../CURRICULUM.md), then use:

- [Prerequisites](prerequisites.md)
- [Development setup](development-setup.md)
- [Learning outcomes](learning-outcomes.md)
- [Assessment and submissions](assessment.md)

The official course has 120 contact hours. Practice-bank extensions and the proposed capstone require independent work. Students should keep a personal evidence log; the shared repository does not store student grades.
