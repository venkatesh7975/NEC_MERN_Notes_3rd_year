# Learning outcomes and evidence

These outcomes are proposed teaching design based on the source syllabus.

| Outcome | Demonstration |
| --- | --- |
| Explain web roles | Trace a request through browser, server and storage |
| Structure content | Semantic document, labeled form and accessible table |
| Adapt layouts | Same content readable at 360px and 1280px |
| Apply programming logic | Correct conditions and loops with boundary tests |
| Build React interfaces | Reusable props and event-driven state |
| Use Node modules and async work | Small CLI with handled failures |
| Implement Express/REST | Validated routes and consistent responses |
| Compare databases | SQL CRUD/join and MongoDB document queries |
| Release reproducibly | Reviewed Git diff, reproducible build and deployment checklist |
| Apply secure development | Demonstrate injection, XSS and CSRF defenses in local fixtures |

Supplementary outcome: integrate a tested UI, API and database with appropriate ownership checks. See [capstone](../capstone-project/README.md).
