# 🟡 Intermediate Web Development Assignments

## Assignment 1: React 19 Task Manager with LocalStorage
- **Task**: Build a React task management component supporting filters (All, Active, Completed), task search, and persistence.
- **Requirements**: Use `useState`, custom hook `useLocalStorage`, and prop-types.

## Assignment 2: RESTful Express API for Course Management
- **Task**: Build an Express API server for managing courses.
- **Requirements**: Implement routes `GET /api/courses`, `POST /api/courses`, `PUT /api/courses/:id`, `DELETE /api/courses/:id`, with express-validator input validation.
