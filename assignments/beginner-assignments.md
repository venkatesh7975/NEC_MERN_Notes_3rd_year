# 🟢 Beginner Web Development Assignments

## Assignment 1: Semantic Recipe Web Page (HTML5)
- **Task**: Create an HTML5 web page displaying a favorite cooking recipe.
- **Requirements**: Use `<header>`, `<main>`, `<article>`, `<h1>`-`<h3>`, `<ol>` for steps, `<ul>` for ingredients, `<table>` for nutritional facts, and `<img>` with `alt` text.

## Assignment 2: Responsive Card Layout (CSS Flexbox)
- **Task**: Build a 3-card product pricing table.
- **Requirements**: Use `display: flex`, center cards horizontally and vertically, add hover scaling effect, and stack cards vertically on mobile screens (< 600px).

## Assignment 3: Interactive Dynamic Counter & Theme (JavaScript)
- **Task**: Create a web page with a number counter (Increment, Decrement, Reset) and a theme toggle button.
- **Requirements**: Write ES6 functions, DOM event listeners, and prevent counter from dropping below zero.
