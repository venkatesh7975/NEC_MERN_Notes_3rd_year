# Express.js

Official module 7; 10 hours shared across its tracks.

## Prerequisites

Node and HTTP.

## Learning objective

Explain and demonstrate routing, middleware, static files, errors through tested examples.

## Study sequence

1. [Teaching notes](notes.md) and worked example.
2. [Daily practice](../../daily-practice/express/README.md).
3. [Assignment](../../tasks/course-express/README.md).
4. [Ten mini-projects](../../mini-projects/express/README.md) in increasing difficulty.
5. [Interview questions](../../interview-preparation/express.md).
6. [Capstone application](../../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: GET /courses returns 200 with three records. Then explain one failing input and how you handled it. Use the [roadmap](../../ROADMAP.md) for the required classroom selection.
