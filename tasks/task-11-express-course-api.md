# Task 11: RESTful Express API for Course Management

## 📌 Task Overview
Build an Express API backend application for managing educational courses with full CRUD routes and input validation.

## 🎯 Requirements & Checklist
- `[ ]` **Endpoints**:
  - `GET /api/courses` - Fetch course list
  - `POST /api/courses` - Create new course
  - `PUT /api/courses/:id` - Update existing course
  - `DELETE /api/courses/:id` - Remove course
- `[ ]` **Validation**: Use `express-validator` middleware for payload sanity checks.
