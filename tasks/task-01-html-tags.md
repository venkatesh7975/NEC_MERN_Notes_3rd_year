# Task 01: Create a Website Containing All HTML Tags

## 📌 Task Overview
Create a comprehensive single-page or multi-page website that demonstrates the usage of standard HTML5 elements and tag categories.

## 🎯 Requirements & Checklist
- `[x]` **Document Structure**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<title>`, `<meta>`.
- `[x]` **Headings & Text**: `<h1>` through `<h6>`, `<p>`, `<span>`, `<strong>`, `<em>`, `<mark>`, `<small>`, `<sub>`, `<sup>`, `<del>`, `<ins>`.
- `[x]` **Lists**: `<ol>` (ordered list), `<ul>` (unordered list), `<dl>` (description list with `<dt>` and `<dd>`).
- `[x]` **Semantic Layout**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
- `[x]` **Links & Media**: `<a>` (internal & external links), `<img>` with `alt`, `<audio>`, `<video>`, `<iframe>`.
- `[x]` **Tables & Forms**: `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<form>`, `<input>` (text, email, password, radio, checkbox, submit), `<textarea>`, `<select>`, `<button>`.
