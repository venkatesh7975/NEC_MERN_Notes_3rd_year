# Task 2: Create a resume using HTML and CSS

## 📌 Task Description
Design and build a clean, professional personal portfolio resume webpage using semantic HTML5 and custom CSS3 styling.

## 🎯 Requirements
- **Header Section**: Full name, title, contact details (Email, Phone, GitHub, LinkedIn), and profile image.
- **About Me / Summary**: Professional bio summarizing goals and background.
- **Education & Experience**: Structured layout detailing academic background, projects, or work experience.
- **Skills Section**: Technical skills list or badges (HTML, CSS, JavaScript, MERN Stack).
- **CSS Styling**: Custom font styles, structured padding/margins, custom color scheme, and clean visual layout.
