# Task 08: Responsive Card Layout (CSS Flexbox)

## 📌 Task Overview
Build a 3-card product pricing table using CSS Flexbox with smooth responsive behavior.

## 🎯 Requirements & Checklist
- `[ ]` **Flexbox Layout**: Use `display: flex`, center cards horizontally and vertically.
- `[ ]` **Interactivity**: Add smooth hover scaling effect (`transform: scale()`, `transition`).
- `[ ]` **Mobile Responsiveness**: Stack cards vertically on screens narrower than 600px using media queries.
