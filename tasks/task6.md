# Task 6: Maintain an Excel track sheet of tasks that you have completed

## 📌 Task Description
Maintain a structured tracking spreadsheet (Excel / Google Sheets / Markdown Tracker) logging all completed daily tasks, problem-solving progress, start/completion dates, and submission notes.

## 🎯 Requirements
- **Tracking Table Format**: Include columns for Task Number, Task Description, Category, Start Date, Completion Date, Status, and Link to Code.
- **Regular Maintenance**: Keep tracking record continuously updated as new tasks are completed.
