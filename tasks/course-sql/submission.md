# Submit course-sql

1. Use your own fork or student repository, under submissions/course-sql/.
2. Include source, fixtures, README and evidence.md. Record actual observations rather than expected results copied as evidence.
3. Submit repository URL and commit SHA through the [existing course form](https://forms.gle/rLbFcq6srWqrWnWh9) when instructed by faculty.
4. Use the classroom deadline; none is invented here. Keep personal identifiers in the faculty channel, not public fixtures.

Track not started -> in progress -> submitted -> reviewed -> revised. A repository brief does not certify completion.
