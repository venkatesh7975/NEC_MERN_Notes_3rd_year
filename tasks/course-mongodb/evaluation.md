# Evaluation rubric

Proposed teaching rubric, not an official university policy.

| Criterion | Points | Evidence |
| --- | --- | --- |
| Required behavior | 40 | Distribute equally across functional requirements |
| Validation and boundaries | 20 | Missing, boundary and repeat cases |
| Required technology and structure | 15 | Readable source using assigned concepts |
| Reproducibility | 15 | Fresh-run instructions, dependencies and fixtures |
| Explanation | 10 | Trace result and explain one corrected bug |
| Total | 100 | Record actual criterion scores |

Recommend 70/100 plus a passing core acceptance example as a learning gate. Award partial credit according to demonstrated behavior, record reasons, and allow a correction with repeated checks. Optional extensions do not replace core work.
