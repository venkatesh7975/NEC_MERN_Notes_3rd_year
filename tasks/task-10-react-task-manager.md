# Task 10: React Task Manager with LocalStorage

## 📌 Task Overview
Build a React component supporting task creation, task completion status, status filtering (All, Active, Completed), search, and persistent storage.

## 🎯 Requirements & Checklist
- `[ ]` **State Management**: `useState` for task lists and filter states.
- `[ ]` **Persistence**: Custom hook `useLocalStorage` or `useEffect` sync with browser `localStorage`.
- `[ ]` **Filter & Search**: Dynamic filtering of task items based on input.
