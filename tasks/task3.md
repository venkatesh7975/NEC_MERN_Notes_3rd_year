# Task 3: Create a responsive website that adapts its content width and styles according to screen sizes

## 📌 Task Description
Develop a responsive web layout that dynamically adapts its layout, typography, and element placement to various screen dimensions (Desktop, Tablet, and Mobile).

## 🎯 Requirements
- **Viewport Config**: Include `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
- **CSS Media Queries**: Implement `@media` rules targeting Desktop (>=1024px), Tablet (768px-1023px), and Mobile (<768px).
- **Flexible Grid/Flexbox**: Use CSS Flexbox or CSS Grid for liquid, screen-adaptive layout behavior.
- **Responsive Typography & Images**: Fluid font sizing (`rem`/`em`) and fluid image scaling (`max-width: 100%`).
