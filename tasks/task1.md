# Task 1: Create a website that contains all types of HTML tags

## 📌 Task Description
Create a comprehensive website that incorporates and demonstrates all standard HTML5 tags and elements.

## 🎯 Requirements
- **Document Structure Tags**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<meta>`, `<body>`
- **Text & Heading Tags**: `<h1>` to `<h6>`, `<p>`, `<span>`, `<strong>`, `<em>`, `<mark>`, `<small>`, `<sub>`, `<sup>`
- **List Tags**: `<ol>`, `<ul>`, `<li>`, `<dl>`, `<dt>`, `<dd>`
- **Semantic Layout Tags**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- **Media & Link Tags**: `<a>`, `<img>`, `<audio>`, `<video>`, `<iframe>`
- **Form & Table Tags**: `<form>`, `<input>`, `<textarea>`, `<select>`, `<option>`, `<button>`, `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
