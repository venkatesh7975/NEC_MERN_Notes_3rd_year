# Task 09: Interactive Dynamic Counter & Theme Toggle (JavaScript)

## 📌 Task Overview
Create an interactive web page with a number counter (Increment, Decrement, Reset) and dark/light theme switcher using vanilla JavaScript DOM manipulation.

## 🎯 Requirements & Checklist
- `[ ]` **Counter Controls**: Buttons for Increment, Decrement, and Reset.
- `[ ]` **Validation**: Prevent counter from dropping below zero.
- `[ ]` **Theme Switcher**: Toggle dark/light themes dynamically on body class.
