# Assignment: Library checkout tracker

ID: course-javascript. Status: specification ready. Estimated work: 3–4 hours of independent practice unless faculty selects a shorter subset.

## Objective

Apply data types, operators, conditions, loops and verify the result.

## Background

A fictional college needs library checkout tracker.

## Problem statement

Add and return books by ID; prevent a second checkout of the same copy.

## Requirements

Complete all functional requirements and submit reproducible evidence.

## Functional requirements

1. Add and return books by ID.
2. prevent a second checkout of the same copy.

## Technical requirements

Use HTML, CSS, JavaScript. Prerequisites: HTML and CSS. See [the full project contract](../../mini-projects/javascript/06-library-checkout-tracker/README.md) for UI/API/database and run requirements.

## Restrictions

Use fictional data. Do not overwrite shared examples or submit only screenshots. Attribute reused code and be able to explain it.

## Expected output

Checkout B1 twice leaves exactly one active loan.

## Example

Use the acceptance scenario above as a fixture; document exact input/action and resulting state.

## Edge cases

Test missing input, a boundary implied by a functional requirement, and repeated execution or interaction.

## Deliverables
