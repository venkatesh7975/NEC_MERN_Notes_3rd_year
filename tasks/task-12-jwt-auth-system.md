# Task 12: JWT Authentication & Role-Based Access Control (RBAC) System

## 📌 Task Overview
Build a secure authentication subsystem with Express and MongoDB featuring password hashing with bcrypt, JWT token generation, and authorization middleware (`student`, `instructor`, `admin`).

## 🎯 Requirements & Checklist
- `[ ]` **User Model**: Mongoose schema with email validation and hashed passwords.
- `[ ]` **Auth Controller**: Register, Login, Token Generation (`jwt.sign`), Verification (`jwt.verify`).
- `[ ]` **Role Middleware**: Access control restricting endpoints based on user roles.
