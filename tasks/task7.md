# Task 7: Counter Application

## 📌 Objective
Create a **Counter Application** using HTML, CSS, and JavaScript.

## 🎯 Requirements

1. **Heading**: Display heading `Counter`.
2. **Current Counter Value**:
   - Initial value should be `0`.
3. **Control Buttons**:
   - **Increment** → Increase counter by `1`.
   - **Decrement** → Decrease counter by `1`.
   - **Reset** → Set counter back to `0`.
4. **Dynamic Color Rules**:
   - Counter > `0` → **Green** (`#2ea44f` / `green`)
   - Counter < `0` → **Red** (`#d73a49` / `red`)
   - Counter === `0` → **Black** (`#24292e` / `black`)
5. **Important Requirement**:
   - Color changes dynamically whenever the counter value changes.

## 💡 Concepts Used
- Variables & Functions
- DOM selection (`querySelector`, `getElementById`)
- `textContent`
- `addEventListener()`
- Conditional statements (`if`, `else if`, `else`)
- DOM styling (`element.style.color`)
