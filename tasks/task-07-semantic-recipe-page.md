# Task 07: Semantic Recipe Web Page (HTML5)

## 📌 Task Overview
Create an HTML5 web page displaying a favorite cooking recipe using proper semantic structure.

## 🎯 Requirements & Checklist
- `[ ]` **Semantic Tags**: Use `<header>`, `<main>`, `<article>`, `<h1>`-`<h3>`.
- `[ ]` **Lists**: `<ol>` for step-by-step instructions, `<ul>` for ingredient lists.
- `[ ]` **Tables & Media**: `<table>` for nutritional facts, `<img>` with descriptive `alt` text.
