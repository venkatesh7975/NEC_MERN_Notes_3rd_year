# Task 03: Create a Responsive Website for Multiple Screen Sizes

## 📌 Task Overview
Design and implement a responsive web application that adapts layout, typography, and styling seamlessly across mobile, tablet, and desktop viewports.

## 🎯 Requirements & Checklist
- `[x]` **Viewport Meta Tag**: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
- `[x]` **Media Queries**: Custom `@media` rules for Desktop (>=1024px), Tablet (768px-1023px), and Mobile (<768px).
- `[x]` **Flexible Layouts**: CSS Grid or Flexbox layout that wraps elements automatically.
- `[x]` **Responsive Images & Text**: Percentage widths (`width: 100%`, `max-width`), `rem`/`em` typography units.
- `[x]` **Mobile Navigation**: Collapsible menu or hamburger navigation for small screens.
