# JavaScript Runnable Code Examples

This directory contains runnable JavaScript ES6+ scripts:
- `001-basic/app.js` — Variables (`const`/`let`), functions, template literals, and array methods.
- `002-intermediate/app.js` — Promises, `async`/`await`, ES Modules, and Object destructuring.
- `003-advanced/app.js` — Custom Event Emitters, Closures, Polyfills, and Debounce/Throttle utilities.

## How to Run
Run directly with Node.js:
```bash
node 001-basic/app.js
node 002-intermediate/app.js
node 003-advanced/app.js
```
