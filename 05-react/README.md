# React

Official module 5; 21 hours shared across its tracks.

## Prerequisites

JavaScript functions, arrays and events.

## Learning objective

Explain and demonstrate jsx, components, props, state, events through tested examples.

1. [Teaching notes](notes.md) and worked example.

3. [Assignment](../tasks/course-react/README.md).

5. [Interview questions](../interview-preparation/react.md).
6. [Capstone application](../capstone-project/README.md).

## Exit criteria

Demonstrate project 1's expected result: Three input records produce three badges. Then explain one failing input and how you handled it. Use the [roadmap](../ROADMAP.md) for the required classroom selection.
