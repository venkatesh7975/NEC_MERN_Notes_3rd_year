## 📌 How to Upload Daily Code
1. Navigate to the relevant technology folder (`html`, `css`, `javascript`, etc.).
2. Select the difficulty level folder (`001-basic`, `002-intermediate`, `003-advanced`).
3. Add your daily code file (e.g., `index.html`, `app.js`, `queries.sql`).
