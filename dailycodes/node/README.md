# Node.js Runnable Code Examples

This directory contains Node.js runtime code examples:
- `001-basic/index.js` — HTTP module server, process argv parsing, and environment configuration.
- `002-intermediate/index.js` — Asynchronous file system (`fs.promises`) reading, writing, and JSON serialization.
- `003-advanced/index.js` — Stream chunk piping (`fs.createReadStream`) and Event Emitter architecture.

## How to Run
```bash
node 001-basic/index.js
node 002-intermediate/index.js
node 003-advanced/index.js
```
