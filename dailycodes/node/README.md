# Node core-module examples

Run from repository root:

- node dailycodes/node/001-basic/index.js — HTTP JSON server on 5050, automatically stops after two seconds.
- node dailycodes/node/002-intermediate/index.js — writes, reads and deletes its own temp_notes.txt fixture; do not place valuable data at that filename.
- node dailycodes/node/003-advanced/index.js — readable stream and event emitter messages.

No npm dependencies required. These examples do not include clustering or HTTP range streaming. [Curriculum track](../../06-nodejs/README.md).
