# Day 1: Resource contract catalog

## Learning objective

Apply resources, methods, status codes, statelessness to the selected behavior.

## Concepts

Implement collection and item reads; document representations.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement implement collection and item reads using a minimal fixture.
2. Add document representations.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Missing item returns 404. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Resource contract catalog](../../../mini-projects/rest-api/01-resource-contract-catalog/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
