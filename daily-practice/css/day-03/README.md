# Day 3: Dashboard shell

## Learning objective

Apply selectors, box model, flexbox, grid, responsive layout to the selected behavior.

## Concepts

Build sidebar, header and content areas; collapse navigation into normal flow on narrow screens.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement build sidebar, header and content areas using a minimal fixture.
2. Add collapse navigation into normal flow on narrow screens.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

The reading order remains navigation then content. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Dashboard shell](../../../mini-projects/css/07-dashboard-shell/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
