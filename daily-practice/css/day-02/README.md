# Day 2: Faculty card row

## Learning objective

Apply selectors, box model, flexbox, grid, responsive layout to the selected behavior.

## Concepts

Build wrapping Flexbox cards with equal visual spacing and flexible widths.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement build wrapping flexbox cards with equal visual spacing and flexible widths using a minimal fixture.
2. Add a second contrasting input and a labeled result.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Five cards wrap at 360px instead of overflowing. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Faculty card row](../../../mini-projects/css/04-faculty-card-row/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
