# Day 1: Notice card

## Learning objective

Apply selectors, box model, flexbox, grid, responsive layout to the selected behavior.

## Concepts

Style one notice with consistent padding and border-box; compare its measured width to content-box.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement style one notice with consistent padding and border-box using a minimal fixture.
2. Add compare its measured width to content-box.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

A 240px border-box card stays 240px wide including padding. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Notice card](../../../mini-projects/css/01-notice-card/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
