# Day 1: Department contact card

## Learning objective

Apply semantics, text, links, lists, tables, forms to the selected behavior.

## Concepts

Use header, main and footer; include email and telephone links; give the page one descriptive h1.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement use header, main and footer using a minimal fixture.
2. Add include email and telephone links.
3. Implement give the page one descriptive h1.

## Expected output

A keyboard user can activate both contact links. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Department contact card](../../../mini-projects/html/01-department-contact-card/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
