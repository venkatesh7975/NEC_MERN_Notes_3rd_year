# Day 2: Class timetable

## Learning objective

Apply semantics, text, links, lists, tables, forms to the selected behavior.

## Concepts

Build a five-day timetable with caption, headers and scope attributes; represent one free slot explicitly.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement build a five-day timetable with caption, headers and scope attributes using a minimal fixture.
2. Add represent one free slot explicitly.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

A reader can associate each lab with its day and time. For invalid data, record the specific expected rejection or fallback before running it.

## Expected learning outcome
