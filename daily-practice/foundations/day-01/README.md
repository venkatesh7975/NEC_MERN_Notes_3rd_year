# Day 1: Request diary

## Learning objective

Apply url, request, response, frontend, backend to the selected behavior.

## Concepts

Record five local page requests with method, path, status and content type; distinguish a cached response from a fresh one.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement record five local page requests with method, path, status and content type using a minimal fixture.
2. Add distinguish a cached response from a fresh one.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Reload index.html; record document and stylesheet requests. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Request diary](../../../mini-projects/foundations/01-request-diary/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
