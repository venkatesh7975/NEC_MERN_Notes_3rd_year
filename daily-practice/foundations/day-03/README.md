# Day 3: Request lifecycle demonstrator

## Learning objective

Apply url, request, response, frontend, backend to the selected behavior.

## Concepts

Create a local request trace with success, missing path and malformed input; explain each response.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement create a local request trace with success, missing path and malformed input using a minimal fixture.
2. Add explain each response.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Existing path succeeds; unknown path returns 404. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Request lifecycle demonstrator](../../../mini-projects/foundations/07-request-lifecycle-demonstrator/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
