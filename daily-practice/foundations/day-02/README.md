# Day 2: Client server responsibility map

## Learning objective

Apply url, request, response, frontend, backend to the selected behavior.

## Concepts

Build a small HTML diagram for enrollment; label validation, storage and rendering responsibilities.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement build a small html diagram for enrollment using a minimal fixture.
2. Add label validation, storage and rendering responsibilities.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

A submitted course ID crosses browser -> API -> database. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Client server responsibility map](../../../mini-projects/foundations/04-client-server-responsibility-map/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
