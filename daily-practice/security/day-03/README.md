# Day 3: Security header verification

## Learning objective

Apply owasp basics, sql injection, xss, csrf to the selected behavior.

## Concepts

Apply restrictive script policy locally; inspect actual headers.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement apply restrictive script policy locally using a minimal fixture.
2. Add inspect actual headers.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Unapproved inline script blocked. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Security header verification](../../../mini-projects/security/07-security-header-verification/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
