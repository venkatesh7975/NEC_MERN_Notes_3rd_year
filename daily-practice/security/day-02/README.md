# Day 2: Rendering boundary lab

## Learning objective

Apply owasp basics, sql injection, xss, csrf to the selected behavior.

## Concepts

Use context-appropriate encoding; disallow unsupported rich HTML.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement use context-appropriate encoding using a minimal fixture.
2. Add disallow unsupported rich HTML.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Untrusted markup remains inert. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Rendering boundary lab](../../../mini-projects/security/04-rendering-boundary-lab/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
