# Day 1: Safe comment renderer

## Learning objective

Apply owasp basics, sql injection, xss, csrf to the selected behavior.

## Concepts

Display text through textContent; test literal markup.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement display text through textcontent using a minimal fixture.
2. Add test literal markup.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

<b>hello</b> appears literally. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Safe comment renderer](../../../mini-projects/security/01-safe-comment-renderer/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
