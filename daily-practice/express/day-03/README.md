# Day 3: Central error handling

## Learning objective

Apply routing, middleware, static files, errors to the selected behavior.

## Concepts

Handle malformed JSON and rejected operations; avoid stack traces in responses.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement handle malformed json and rejected operations using a minimal fixture.
2. Add avoid stack traces in responses.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Malformed JSON returns 400; unexpected failure returns 500. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Central error handling](../../../mini-projects/express/07-central-error-handling/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
