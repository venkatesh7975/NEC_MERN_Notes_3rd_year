# Day 2: Submission portal

## Learning objective

Apply integration, persistence, api contracts, verification to the selected behavior.

## Concepts

Submit URL for assignment; enforce unique user-assignment pair.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement submit url for assignment using a minimal fixture.
2. Add enforce unique user-assignment pair.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Duplicate submission returns conflict. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Submission portal](../../../mini-projects/fullstack/04-submission-portal/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
