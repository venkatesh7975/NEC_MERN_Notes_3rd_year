# Day 1: Course directory slice

## Learning objective

Apply integration, persistence, api contracts, verification to the selected behavior.

## Concepts

Load persisted courses through Express into React; show loading/error.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement load persisted courses through express into react using a minimal fixture.
2. Add show loading/error.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Reload retains database course titles. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Course directory slice](../../../mini-projects/fullstack/01-course-directory-slice/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
