# Day 2: Role permission matrix

## Learning objective

Apply passwords, sessions, identity, ownership, roles to the selected behavior.

## Concepts

Define learner and faculty permissions; enforce server-side.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement define learner and faculty permissions using a minimal fixture.
2. Add enforce server-side.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Learner cannot create assessment. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Role permission matrix](../../../mini-projects/authentication/04-role-permission-matrix/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
