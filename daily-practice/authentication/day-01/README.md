# Day 1: Password verification lab

## Learning objective

Apply passwords, sessions, identity, ownership, roles to the selected behavior.

## Concepts

Hash fictional passwords with a password-hashing library; verify matches.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement hash fictional passwords with a password-hashing library using a minimal fixture.
2. Add verify matches.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Correct input matches; wrong input fails. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Password verification lab](../../../mini-projects/authentication/01-password-verification-lab/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
