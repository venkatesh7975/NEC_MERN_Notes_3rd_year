# Day 3: Password reset simulator

## Learning objective

Apply passwords, sessions, identity, ownership, roles to the selected behavior.

## Concepts

Store hashed expiring single-use tokens; simulate delivery locally.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement store hashed expiring single-use tokens using a minimal fixture.
2. Add simulate delivery locally.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Used reset token cannot be replayed. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Password reset simulator](../../../mini-projects/authentication/07-password-reset-simulator/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
