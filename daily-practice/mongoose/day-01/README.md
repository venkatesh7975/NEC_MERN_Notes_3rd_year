# Day 1: Course schema validator

## Learning objective

Apply schemas, validation, indexes, references to the selected behavior.

## Concepts

Require title and nonnegative hours; validate before write.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement require title and nonnegative hours using a minimal fixture.
2. Add validate before write.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Negative hours fails validation. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Course schema validator](../../../mini-projects/mongoose/01-course-schema-validator/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
