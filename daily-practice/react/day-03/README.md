# Day 3: Editable assignment board

## Learning objective

Apply jsx, components, props, state, events to the selected behavior.

## Concepts

Create edit remove and filter tasks; preserve IDs and status on edits.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement create edit remove and filter tasks using a minimal fixture.
2. Add preserve IDs and status on edits.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Renaming leaves completion unchanged. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Editable assignment board](../../../mini-projects/react/07-editable-assignment-board/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
