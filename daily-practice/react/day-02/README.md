# Day 2: Controlled feedback form

## Learning objective

Apply jsx, components, props, state, events to the selected behavior.

## Concepts

Validate required name and rating 1–5; reset after local submission.

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement validate required name and rating 1–5 using a minimal fixture.
2. Add reset after local submission.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Blank name prevents submission. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Controlled feedback form](../../../mini-projects/react/04-controlled-feedback-form/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
