# Day 1: Course badge gallery

## Learning objective

Apply jsx, components, props, state, events to the selected behavior.

## Concepts

Render three components with title and level props; use stable IDs.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement render three components with title and level props using a minimal fixture.
2. Add use stable IDs.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Three input records produce three badges. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Course badge gallery](../../../mini-projects/react/01-course-badge-gallery/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
