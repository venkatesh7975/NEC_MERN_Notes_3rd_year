# Day 1: Attendance eligibility calculator

## Learning objective

Apply data types, operators, conditions, loops to the selected behavior.

## Concepts

Validate present and total counts; compute percentage; use a 75 percent practice threshold.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement validate present and total counts using a minimal fixture.
2. Add compute percentage.
3. Implement use a 75 percent practice threshold.

## Expected output

15 of 20 yields 75 percent and eligible; total 0 is rejected. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Attendance eligibility calculator](../../../mini-projects/javascript/01-attendance-eligibility-calculator/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
