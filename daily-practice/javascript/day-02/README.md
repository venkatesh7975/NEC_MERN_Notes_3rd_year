## Concepts

## Difficulty

🟡 Intermediate.

## Coding exercises

1. Implement filter six course objects by case-insensitive title using a minimal fixture.
2. Add display result count and empty state.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Searching react finds React; unmatched text shows zero results. For invalid data, record the specific expected rejection or fallback before running it.
