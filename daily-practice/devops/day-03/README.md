# Day 3: CI quality gate

## Learning objective

Apply git, github, ci/cd, docker, react deployment to the selected behavior.

## Concepts

Run link and build checks; demonstrate a failing fixture.

## Difficulty

🔴 Advanced.

## Coding exercises

1. Implement run link and build checks using a minimal fixture.
2. Add demonstrate a failing fixture.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Broken fixture fails the job. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [CI quality gate](../../../mini-projects/devops/07-ci-quality-gate/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
