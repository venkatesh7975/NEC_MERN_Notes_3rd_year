# Day 1: Git change journal

## Learning objective

Apply git, github, ci/cd, docker, react deployment to the selected behavior.

## Concepts

Create three commits in scratch repo; explain stage and worktree.

## Difficulty

🟢 Beginner.

## Coding exercises

1. Implement create three commits in scratch repo using a minimal fixture.
2. Add explain stage and worktree.
3. Implement an explicit guard or fallback for missing input/content.

## Expected output

Log contains three distinct changes. For invalid data, record the specific expected rejection or fallback before running it.

## Challenge problem

Complete the remaining behavior in [Git change journal](../../../mini-projects/devops/01-git-change-journal/README.md); introduce a repeated action or boundary value and explain the result.

## Expected learning outcome

Demonstrate and explain the governing rule, with source plus actual evidence. Completion requires observed behavior, not merely time spent.
